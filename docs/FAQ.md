# 常见问题

## 微信发了消息没有回复

先确认对应 profile 的服务正在运行，并查看最近日志是否完成预热、是否有认证或网络错误。
核对 muse-cli 登录用户、Muse 对话编号、微信绑定用户是否与该 profile 一致。
安装与环境配置见 [DEPLOY.md](DEPLOY.md)；每个 profile 只运行一个消费者。
仅有自动重启无法修复登录失效、上游限制或出口网络故障，需处理日志中的实际原因。

## 收到文字，但没有收到文件

以微信真正收到且能打开的附件为准。按 [ACCEPTANCE.md](ACCEPTANCE.md) 核对每个附件的
回执；文字发送成功不代表附件发送成功。附件 URL 暂时不可用时有有限重试；明确拒绝或
不明确的发送结果需要先核对，避免重复投递。报错时提供脱敏的版本、时间和错误类型。

## 提醒只回复“正在处理中”，或到时没有消息

使用“提醒我1分钟后 测试提醒”这样的明确命令，先核对收到“已设置提醒”，
再通过“提醒列表”检查。过去、模糊或不存在的日期不会创建；时间按北京时间解释。
主动发送依赖本人最近的微信上下文。上下文失效时可能要本人重新发一条消息后补送。
未知发送结果不会自动重复发送。新环境首次使用必须按 [日常工具](DAILY_TOOLS.md) 实测。

## 能再绑定一个微信吗

可以。按 [MULTI_ACCOUNT.md](MULTI_ACCOUNT.md) 创建独立 profile 和 Muse 对话，
使用家人的微信扫码。每人独立数据目录，不复制默认微信的登录态；共用 Muse 账号仍
共用其权限和费用。若需要账户级权限隔离，应使用独立 Muse 账号与运行环境。

## 视频为什么没有声音转写

需要 ffmpeg 和实际可执行的 faster-whisper CLI/wrapper，以及服务用户可读的模型缓存。
无音轨、音量不足、非语音或工具缺失都应如实说明。安装库成功或退出码为 0 不能证明转写正确。
配置与测试步骤见 [DEPLOY.md](DEPLOY.md)；公开验证范围见 [验收摘要](../FINAL-REPORT.md)。

## 关闭索引会删除我的历史吗

“偏好 索引关”停止新文件进入资料索引，保留已有索引、任务和 Muse 服务端历史。
本项目不提供一条命令自动清空全部历史。数据处理应先备份，并分别核对本地和 Muse 的保存范围。
